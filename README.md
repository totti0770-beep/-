# NESP · منصة الإدارة التنفيذية للخدمات التمريضية - مستشفى جازان التخصصي
**NESP — Nursing Executive Services Management Platform · Jazan Specialist Hospital**

منصة برمجية تنفيذيّة متكاملة لإدارة الكفاءات التمريضية، متابعة الأداء الإكلينيكي، البحث والتصفية، وتفعيل التحفيز عبر نظام التكريم والجوائز (Gamification).

> **الهوية البصرية / Branding:** واجهة المنصة مبنية على هوية **NESP** (كحلي `#102037` وأزرق `#3C78A8`، خط IBM Plex Sans Arabic، وشعار NESP). ملفات الهوية الكاملة (الرموز، التوكنز، الإرشادات) موجودة في مجلد [`brand/`](brand/)، وأصول التشغيل في [`static/nesp/`](static/nesp/).

---

## 🚀 المميزات المكتملة في المنصة (المراحل 1 - 5)

1. **المرحلة 1 - الهيكل والتأسيس:**
   - بنية MVC متطورة باستخدام Flask و SQLAlchemy.
   - دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL).
   - تصميم متجاوب باستخدام Tailwind CSS.

2. **المرحلة 2 - المصادقة والملفات الشخصية:**
   - نظام دخول وخروج آمن مع جلسات مسجلة (Sessions) وتشفير كلمات المرور.
   - صفحة ملف شخصي مستقلة لكل ممرض وممرضة.

3. **المرحلة 3 - لوحة التحكم الديناميكية:**
   - كروت مؤشرات أداء حية (KPIs) تُحسب أوتوماتيكياً.
   - جدول متابعة أحدث الانضمامات التمريضية.

4. **المرحلة 4 - قاعدة بيانات الموظفين (البحث والتصفية):**
   - محرك بحث ذكي حسب الاسم أو الرقم الوظيفي.
   - تصفية متقدمة حسب القسم والحالة المهنية.

5. **المرحلة 5 - نظام التكريم والجوائز (Gamification):**
   - إسناد أوسمة بشارات تفاعلية للموظفين.
   - لوحة شرف تاريخية مرتبطة بالملفات الشخصية.

## 🛠️ كيفية التثبيت والتشغيل المحلي

```bash
pip install -r requirements.txt
flask seed-db
python app.py
```
افتح المتصفح على: `http://127.0.0.1:5000`
- الرقم الوظيفي للتجربة: `JSH1001`
- كلمة المرور: `Jazan2026`
